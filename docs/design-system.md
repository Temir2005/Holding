# Дизайн-система «Чертёж»

Выбрана 21.10.2026: основа A «Чертёж» плюс сцена полного цикла из C «Система». Акцент красный. Прототип и обоснование: `design/stage-0.md`, `design/concepts/chertezh/` (контракт линии и сцены — в его `README.md`). Живая витрина всех токенов и компонентов — `/ru/dev/design`; она есть только в dev-сборке.

## Принцип
Сайт свёрстан как комплект архитектурных чертежей: бумага, тёплый графит и одна красная линия. Линия проходит через всю страницу и показывает полный цикл. Каждая секция — «лист»:
- линейка по верхнему краю;
- тихая сетка из 12 колонок;
- широкое левое поле, в котором идёт линия.

## Токены (`frontend/src/styles/tokens.css`, `tailwind.config.ts`)
- **Палитра:**
  - бумага `#F3F2EE`, чернила `#171715` (16:1);
  - графит `#141413`, мел `#ECEAE4` (15.3:1);
  - красный `#E0482B` — только линии и марки;
  - красный для текста: `#B3361B` на бумаге (5.4:1), `#EE5F42` на графите (5.6:1);
  - accent-тон: заливка `#E5553A`, текст и линия становятся графитовыми.
- **Семантика по тонам** (классы `.tone-light`, `.tone-dark`, `.tone-accent`): `surface`, `surface-2`, `fg`, `fg-mute`, `line`, `line-strong`, `plate` (заглушка изображения: на тёмном светлее фона), `trace` (цвет линии), `accent` (красный текст), `on-accent`. Компоненты используют только семантику.
- **Шрифты:** Geologica (инстанс SHRP=60, вес 200–700) и IBM Plex Mono 400/500.
  - Файлы свои, урезанные: `frontend/src/assets/fonts/`, лицензии `OFL-*.txt`, сборка `design/tools/build-fonts.sh`.
  - Казахские буквы проверены по `cmap` (`design/tools/cmap.cjs`).
  - Резервный шрифт `Geologica Fallback` подогнан по метрикам, поэтому заголовок не прыгает при загрузке.
- **Шкала кеглей:** `text-display`, `text-title`, `text-subtitle`, `text-stat-hero`, `text-stat-lg`, `text-lead`, `text-body`, `text-caption`.
  - Для `:lang(kk)` display и title на ступень меньше.
  - Старые имена `text-hero`, `text-h2`, `text-h3` и `text-stat` сохраняют прежние размеры. Они нужны секциям, которые ещё не переделаны (этапы 2–3).
- **Сетка и ритм:**
  - `--pad-l` (поле с линией), `--pad-r`, `--trace-x`, `--gap`;
  - ритм секций `--section-y`;
  - шаг 8 px, линии ровно 1 px, радиусы 0–2 px, теней нет.
- **Слои:** `z-trace`, `z-sticky`, `z-header`, `z-menu`, `z-toast`.
- **Движение:**
  - длительности 150 / 300 / 450 / 700 / 1100 мс;
  - кривые `--ease-out` (0.2, 0.7, 0.2, 1) и `--ease-in-out`;
  - перо `--pen: 78%`.
  - Те же константы для Framer Motion лежат в `src/lib/motion.ts`.

## Компоненты (`frontend/src/components`)
- **`ui/Section`** — лист секции: тон, якорь, ритм, линейка, сетка и отрезок линии `trace` (по умолчанию прямой).
- **`trace/TraceSegment`, `trace/paths`** — контракт линии. Каждый блок входит в верхний край и выходит из нижнего в `--trace-x`, поэтому при любом порядке блоков линия не рвётся. Прогресс рисования — `useScroll` секции с offset `['start 78%', 'end 78%']`. При reduced motion линия просто нарисована.
- **`ui/Container`** — контент листа между полями.
- **`ui/Eyebrow`** — мета-строка «02 / 04 · ПОДПИСЬ», номер берётся из `PageRenderer`.
- **`ui/Heading`** — заголовки шкалы.
- **`ui/SectionHeader`** — шапка листа: мета, заголовок на 8 колонок, aside.
- **`ui/Button` (`CmsLink`, `MoreLink`, `CtaGroup`), `ui/DimArrow`** — квадратные кнопки; стрелка при наведении вытягивается в размерную линию.
- **`.link-draw`** — «чертящееся» подчёркивание.
- **`ui/Tag`, `ui/StatusMark`** — моно-метки; статус проекта показан формой (□ ◩ ■), а не только цветом.
- **`ui/DimensionLine`** — размерная линия |←— подпись —→|.
- **`ui/Frame`** — кадр с метками обреза.
- **`ui/SmartImage`:**
  - фокус-точка редактора задаёт `object-position`;
  - `priority` показывает картинку сразу, без затухания (LCP);
  - без медиа выводится заштрихованная плашка тона.
- **`ui/Reveal`, `motion/ClipReveal`, `motion/CountUp`** — появление при входе в экран. При reduced motion остаётся только прозрачность. `CountUp` держит финальное число в DOM и не сдвигает вёрстку.
- **`motion/usePinnedSteps`** — механика закреплённой сцены:
  - высота секции `100svh + N × 65svh`;
  - активный этап = `floor(p × N)`;
  - нативная прокрутка, без snap и перехвата;
  - при reduced motion или N ≤ 1 — обычный список.

## Правила
- `h1` в hero и картинка первого экрана видны с первого кадра. Анимировать можно только линию, рамку и детали (LCP).
- Красный — это линия. Кнопки красными не бывают.
- Пустых блоков не бывает. Нет фото — плашка тона, нет данных — блок схлопывается.
- Админку эта система не задевает: у неё свой конфиг Tailwind и свои токены, CSS админки не изменился.
