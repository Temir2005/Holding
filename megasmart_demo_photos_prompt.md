# Промпт для Claude Code: демо-фотографии для сайта MegaSmart

Положи файл в корень репозитория (ветка `prototype`) и напиши Claude:
«Прочитай megasmart_demo_photos_prompt.md и работай по нему. Начни с этапа 0».

## Задача

Сейчас все картинки стартового контента рисуются кодом (`backend/seed/images.py`): градиенты и простые фигуры. Чтобы посмотреть, как сайт выглядит с настоящими фотографиями, нужен **набор демо-фото** — реальных стоковых снимков со свободной лицензией, подобранных под каждое место на сайте.

Это только для локального просмотра и показа заказчику. Код и структура контента не меняются, демо-фото не коммитятся.

## Правила

Действуют правила из `CLAUDE.md`: git только с моего разрешения, крупные изменения через согласование. Дополнительно:

- **Не трогать** публичное API, админку, модели и миграции.
- **Новые зависимости — нет.** Для скачивания хватит `httpx`, он уже есть в dev-зависимостях бэкенда.
- **Только фото со свободной лицензией**, разрешающей коммерческое использование: Unsplash License или Pexels License. Никаких картинок из поиска Google, никаких фото с узнаваемыми чужими брендами и логотипами.
- **Ключ API** (Unsplash или Pexels) я дам сам. Он хранится в `.env` как `UNSPLASH_ACCESS_KEY` или `PEXELS_API_KEY` и никуда не выводится и не коммитится.

## Как устроить

1. **Папка-переопределение `backend/seed/photos/`** (в `.gitignore`). Если в ней лежит файл с именем слота (`hero-skyline.jpg`, `site-1.jpg`, `person-cto.jpg` и т.п.), сиды берут его вместо нарисованного кодом. Если файла нет — рисуют как сейчас. Это единственная правка в сидах. Размеры и доминирующий цвет считать из файла.
2. **Скрипт `backend/seed/fetch_photos.py`** и цель `make demo-photos`:
   - для каждого слота — поисковый запрос, ориентация и минимальный размер (таблица ниже);
   - скачивает лучшее совпадение в `seed/photos/`, уменьшая до разумного размера (длинная сторона до 2400 px, JPEG ~85);
   - пишет `seed/photos/CREDITS.md`: слот → автор, ссылка на фото, лицензия (Unsplash просит указывать автора и при скачивании вызывать их download-endpoint — соблюдать);
   - повторный запуск не перекачивает уже скачанное; флаг `--replace <слот>` перекачивает один слот (следующий результат поиска), если фото не понравилось.
3. **Применение:** `make demo-photos`, затем `make seed-force` — сайт пересобирается с фото. Напомни мне, что `seed-force` перезаписывает стартовый контент в моей dev-базе.
